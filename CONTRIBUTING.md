## Required checks

```bash
npm run validate    # verify:kg + verify:arsenal + typecheck + lint + format + coverage + build
npm run test:e2e    # Playwright (required for routing/layout/resume changes)
```

## Knowledge layers (two systems)

1. **`.cursor/knowledge-graph/graph.json`** — hand-curated map of routes, pages, data, and task entry points. Update when you add routes or shared components. Run `npm run verify:kg`.
2. **`.arsenal/`** — generated by [Arsenal context engine](../Arsenal/docs/using-arsenal-in-any-repo.md): repo map, dependency graph, file summaries, token-efficient context. Regenerate after large refactors:

```bash
npm run context:refresh   # index + summarize + graph (requires sibling Arsenal checkout)
npm run verify:arsenal
```

Commit `.arsenal/` outputs except `.arsenal/cache/` (gitignored).

## Common tasks

| Task        | Where to edit                                                         |
| ----------- | --------------------------------------------------------------------- |
| Site copy   | `src/data/*.ts`                                                       |
| New article | `src/content/articles/*.md` + `src/data/articles.ts` (`articleOrder`) |
| New route   | `src/App.tsx` + `.cursor/knowledge-graph/graph.json` + e2e smoke      |
| Resume      | `src/data/resume.ts`, `resume/main.tex`                               |
