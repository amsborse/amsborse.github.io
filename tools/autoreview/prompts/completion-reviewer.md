# Completion reviewer

Before an agent claims completion:

1. Confirm a task session was used (or warn about fallback scope).
2. Confirm only scoped routes were opened.
3. Confirm screenshot and AI budgets were respected.
4. Confirm critical / high-confidence findings were fixed or honestly reported.
5. Require the wording: “Verification completed for the current task scope.”
6. Forbid the wording: “The entire application has been verified.”
